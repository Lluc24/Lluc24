Before this I graduated first of ~400 in Informatics Engineering at UPC, spent a semester at UC Irvine as a Balsells Fellow doing cooperative game theory under Vijay Vazirani, and did an exchange semester at EPFL.

Off the clock: daily calisthenics, running and cycling outdoors, and Stephen King above any other author.

## Selected projects

- **[ClearPath](https://github.com/Lluc24/yc-hack)** · YC Voice Agents Hackathon. A Pipecat agent that fills a live React medical intake form as the patient speaks.
- **[divergence](https://github.com/Lluc24/divergence)** · A divergence check for Scala 3 match types ([compiler PR](https://github.com/scala/scala3/pull/24661)), endorsed by Martin Odersky and proposed as a [Scala Improvement Process](https://github.com/scala/improvement-proposals/pull/136).
- **[leximin](https://github.com/Lluc24/leximin)** · First public implementation of Vazirani's ACM EC algorithm for leximin-fair profit allocation.
- **[Healix](https://github.com/KianBahia/SUI_Hack)** · SUI Foundation Hackathon $1,000 prize winner. An encrypted mood journal on the Sui blockchain.
